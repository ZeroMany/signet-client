# Security policy

Signet stores passwords, so security reports are taken seriously.

## Reporting a problem

Please **don't** open a public issue for a security problem. Instead, use
GitHub's private reporting: open the repository's **Security** tab and click
**Report a vulnerability**. Only the maintainer can see the report.

Include what you found, how to reproduce it, and what an attacker could do
with it. You'll get a reply as soon as possible. This is a hobby project run
by one person, so please be patient.

## Supported versions

Only the latest code on the `main` branch is supported.

The firmware for the Signet device itself is not part of this repository.
