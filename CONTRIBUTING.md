# Contributing

Thanks for your interest in Signet! This is a hobby fork of the original
[nthdimtech/signet-client](https://github.com/nthdimtech/signet-client), which
is no longer maintained.

## Ideas and bug reports

Open an [issue](../../issues). Tell us what you expected, what happened
instead, and which system you use (Windows, Linux or macOS). Screenshots help.

## Pull requests

Small, focused pull requests are welcome.

1. Fork the repository and create a branch from `main`.
2. Make your change. [HOW-TO-BUILD.md](HOW-TO-BUILD.md) explains how to build
   the app on your own computer.
3. Open a pull request into `main` and describe what it changes and why.

Every pull request is built automatically for Windows and Linux. Please make
sure the build passes. For larger changes, open an issue first so we can talk
about it before you spend time on it.

## Security problems

Please don't report security problems in public issues. See
[SECURITY.md](SECURITY.md) instead.
